# Wallpaper

Менеджер обоев для Windows 11. Разные обои и плейлисты на каждом мониторе, слайд-шоу,
иконка в трее, глобальные горячие клавиши. Полная спецификация — [SPEC.md](SPEC.md).

**Текущий этап: v0.5** — видео и веб-обои, плейлисты из видео, окно настроек, расписание, оверлей быстрого выбора.

## Сборка и запуск

```bash
dotnet build src/Wallpaper/Wallpaper.csproj -c Release
```

```bash
./src/Wallpaper/bin/Release/net10.0-windows/Wallpaper.exe
```

Нужен .NET 10 SDK. Один NuGet-пакет — обёртка WebView2 для веб-обоев.

Готовая папка для переноса на другую машину:

```bash
dotnet publish src/Wallpaper/Wallpaper.csproj -c Release -o publish
```

## Первый запуск

Приложение садится в трей и на первом запуске открывает окно настроек — там нечего
изучать, достаточно перетащить папку с картинками в сетку.

Если Windows спрятала значок под стрелку «Показать скрытые значки», первый клик по нему
съедает сама выпадашка — это поведение панели задач, не приложения. Перетащи значок из
выпадашки на панель, и клики начнут работать с первого раза.

- **ЛКМ по иконке** — следующие обои на мониторе под курсором
- **Двойной клик** — окно настроек
- **ПКМ** — меню: быстрый выбор, настройки, плейлисты, мониторы по отдельности, вписывание, автозапуск

### Окно настроек

- **Мониторы** — кликабельная схема расположения. Выбираешь монитор, задаёшь ему имя и
  режим: выключено, картинка, плейлист или видео. Вписывание и цвет полей общие для всех
  мониторов — иначе Windows не умеет.
- **Плейлисты** — сетка миниатюр, папки и файлы можно перетаскивать в неё мышью.
  Кнопка **«⟳ Обновить»** перечитывает папки: слежение за файловой системой изредка
  пропускает изменения — по сети, на съёмных дисках, при копировании пачками.
  Клик по плитке ставит картинку сразу, правый клик открывает меню: показать, открыть
  папку и **выключить файл из плейлиста**. Выключенный остаётся в сетке погашенным —
  тем же меню его можно включить обратно. У каждой папки в списке источников есть галка
  **«с подпапками»**. Интервал, порядок, фильтр по имени.
- **Общее** — автозапуск, редактор горячих клавиш (нажал на поле, набрал комбинацию;
  занятая другой программой подсвечивается сразу), состояние видеослоя и правила паузы.

Все изменения применяются немедленно, кнопки «ОК» нет и не будет. Размер и положение окна
запоминаются — оно открывается там же, где его закрыли, даже после перезапуска приложения. Если выключить файл,
который сейчас на экране, обои сменятся сразу, не дожидаясь интервала.

Новые файлы в папках плейлиста подхватываются сами: сетка миниатюр перерисовывается
через секунду после того, как файл появился, вложенные папки тоже отслеживаются.

### Быстрый выбор

<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>W</kbd> раскрывает поверх монитора под курсором сетку
обоев текущего плейлиста. Стрелки — выбор, <kbd>Enter</kbd> — поставить, <kbd>Tab</kbd> —
следующий плейлист, <kbd>Esc</kbd> — закрыть. Просто набирай текст, чтобы отфильтровать по имени файла.

Кнопка **«⟳ Обновить»** и клавиша <kbd>F5</kbd> перечитывают папки, не выходя из оверлея.

Правый клик по плитке открывает то же меню, что и в настройках: показать, выключить из
плейлиста, открыть папку. Выключенные файлы в оверлей не попадают — включить обратно
можно в настройках, там они видны погашенными.

## Видео и веб-обои

Ставятся на монитор так же, как картинка: **Настройки → Мониторы → Режим → Видео или веб**.
В поле можно указать:

- **видео** — mp4, mkv, webm, mov и всё остальное, что играет mpv;
- **анимацию** — gif, apng, анимированный webp;
- **веб-страницу** — локальный `.html` или адрес `https://…`, включая сцены на canvas и WebGL.

Всё это ложится **под иконки рабочего стола**. Звук у видео по умолчанию выключен,
переключается на лету по <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd>.

Веб-обои работают на встроенном в Windows 11 рантайме WebView2 — ставить ничего не нужно.
Для видео нужна libmpv (ниже).

Нужна библиотека **libmpv** — в приложение она не входит: весит больше сотни мегабайт
и распространяется под GPL. Скачай сборку mpv для Windows и положи `libmpv-2.dll`
рядом с `Wallpaper.exe`, в `%APPDATA%\Wallpaper` или укажи папку в `config.json`:

```jsonc
{ "mpvPath": "D:/Soft/libmpv" }
```

Видео глушится само, когда смотреть его всё равно некому. Правила настраиваются:

| Когда | По умолчанию |
|---|---|
| Запущено полноэкранное приложение | пауза |
| Окно закрыло монитор целиком (игры в безрамочном окне) | пауза только этого монитора |
| Ноутбук работает от батареи | пауза |
| Экран заблокирован | пауза |
| Подключение по RDP | пауза |

Расход на двух мониторах 2560×1440 с двумя роликами 4K60 h264: около 22 % одного ядра
из двенадцати и 580 МБ памяти, из которых 120 — сама libmpv.

## Горячие клавиши

Действие применяется к монитору, **под которым сейчас курсор**.

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+→` / `←` | Следующие / предыдущие обои |
| `Ctrl+Alt+Shift+→` | Следующие на всех мониторах |
| `Ctrl+Alt+P` | Пауза слайд-шоу на этом мониторе |
| `Ctrl+Alt+W` | Быстрый выбор |
| `Ctrl+Alt+M` | Звук видео вкл / выкл |
| `Ctrl+Alt+0` | Обои вкл / выкл |
| `Ctrl+Alt+1…3` | Переключить плейлист |
| `Ctrl+Alt+E` | Показать текущую картинку в проводнике |
| `Ctrl+Alt+Q` | Выход из приложения |

Переназначаются в настройках или в `config.json`. Каждую можно выключить галкой рядом —
комбинация при этом остаётся записанной. Если комбинация занята другой программой,
приложение об этом скажет и продолжит работать без неё.

**Пауза помониторная**: на одном экране картинка держится, на соседнем слайд-шоу идёт
дальше. Пауза есть и в меню трея — в подменю каждого монитора, и первым пунктом для того,
под которым сейчас курсор. Снятая пауза отсчитывает интервал заново, а не меняет картинку
в тот же миг.

**Обои вкл/выкл** возвращает то, что стояло в Windows до запуска приложения, и включает
всё обратно. То же самое — галка «Обои включены» в настройках и первый пункт меню в трее.

Пока хоть одному монитору назначено видео или страница, **картинки слайд-шоу тоже рисуются
в слое рабочего стола**, а не ставятся обоями Windows. Иначе каждая смена обоев заставляет
Explorer перестроить рабочий стол и убить окна слоя на соседних мониторах — видео молча
превращается в картинку. Побочный эффект приятный: в этом режиме нужна libmpv, зато смена
картинок не дёргает систему.

Видео и страницы работают и **внутри плейлистов**: положи в папку ролики — они попадут
в сетку миниатюр наравне с картинками и будут меняться по тому же интервалу.
Анимированный gif в плейлисте считается картинкой (Windows покажет первый кадр);
чтобы он двигался, поставь его отдельным режимом «Видео или веб».

## Расписание

**Настройки → Общее → Расписание**: в указанное время плейлист меняется на всех мониторах.
Например, `08:00 → Светлые`, `22:00 → Тёмные`. Расписание кольцевое — до первого правила
суток действует последнее, так что ночью между 00:00 и 08:00 остаются тёмные.

## config.json

Всё, что делает окно настроек, лежит в `%APPDATA%\Wallpaper\config.json`, и его можно
править руками: файл подхватывается **на лету**, перезапуск не нужен, открытое окно
настроек само перерисуется. Комментарии `//` и висящие запятые разрешены.

```jsonc
{
  "fit": "fill",              // center | tile | stretch | fit | fill | span — общее для всех мониторов
  "startWithWindows": true,
  "monitors": {
    "\\\\?\\DISPLAY#SAC2753#...": {
      "label": "Правый",
      "mode": "playlist",     // off | static | playlist
      "playlistId": "nature"
    }
  },
  "playlists": [
    {
      "id": "nature",
      "name": "Природа",
      "folders": [{ "path": "D:/wp/nature", "recursive": true }],
      "files": [],
      "excluded": [],         // выключенные вручную файлы, целиком путём
      "intervalSeconds": 900,
      "order": "shuffle"      // shuffle | sequential
    }
  ]
}
```

ID мониторов взять отсюда:

```bash
./src/Wallpaper/bin/Release/net10.0-windows/Wallpaper.exe --monitors
```

Рядом с конфигом лежат `state.json` (что где сейчас показано, где стоит пауза, какие обои
были до нас и где лежало окно настроек — трогать не надо) и `wallpaper.log` (только ошибки;
если файла нет, значит всё в порядке).

Приложение поднимается ровно там, где закрылось: те же картинки на тех же мониторах, те же
паузы. Картинка при этом досиживает свой интервал, а не отсчитывает его заново.

Обои, которые стояли до нас, возвращаются при выходе и при выключении по
<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>0</kbd>. Приложение проверяет их на каждом запуске:
если на мониторе оказалось не то, что оно ставило само, значит обои выбрал ты — и вернётся
именно твой выбор. Ничего удалять и перезапоминать вручную не нужно; аварийное завершение
тоже не портит запомненное, потому что свои же обои приложение узнаёт.

Закрыть приложение из скрипта, чтобы обои успели вернуться:

```bash
./src/Wallpaper/bin/Release/net10.0-windows/Wallpaper.exe --quit
```

## Проверки

```bash
./src/Wallpaper/bin/Release/net10.0-windows/Wallpaper.exe --selftest
```

Арифметика курсора, детерминированность шаффла, разбор горячих клавиш, формат конфига.

Если видео не показывается — диагностика слоя рабочего стола:

```bash
./src/Wallpaper/bin/Release/net10.0-windows/Wallpaper.exe --workerw
```

Печатает дерево окон рабочего стола, перебирает способы привязки и говорит, какой
работает на этой сборке Windows. Отчёт дублируется в журнал, его удобно приложить к жалобе.
Ключ `--workerw --visual` прогоняет все способы по очереди, заливая экран зелёным, —
на случай, когда автоматический замер цвета врать (например, поверх стола лежит
прозрачный оверлей).

Перебор способов вывода mpv на настоящем файле:

```bash
./src/Wallpaper/bin/Release/net10.0-windows/Wallpaper.exe --videosweep "D:/видео/обои.mp4"
```

## Чего пока нет

- **Плавных переходов между картинками** — API для них в Windows не существует,
  смена жёсткая, как в самой Windows.
- **Разного вписывания на разных мониторах** — `IDesktopWallpaper.SetPosition` не принимает
  ID монитора. Для картинок это не обойти.
- **Плейлистов из видео** — на монитор ставится один ролик или одна страница.
- **Взаимодействия с веб-обоями** — страница живёт сама по себе, мышь и звук системы до неё не доходят.
- Сетка миниатюр рисует максимум 600 плиток за раз; для больших папок есть фильтр по имени.
